## 🎓 Developer Notes

### Installation of New Features
1. Create new page in `/app` or `/app/admin`
2. Create related components in `/components`
3. Add API routes if needed in `/app/api`
4. Add TypeScript interfaces to `/lib/mongodb.ts`
5. Update navigation links
6. Add responsive styles
7. Test on mobile and desktop
8. Update documentation

### Common Patterns

#### Creating a New Admin Page
```tsx
// app/admin/feature/page.tsx
'use client'
import { AdminLayout } from "@/components/admin-layout"
import { useState } from "react"

export default function FeaturePage() {
  return <AdminLayout>{/* content */}</AdminLayout>
}
```

#### Creating API Endpoint
```tsx
// app/api/feature/route.ts
import { NextResponse } from 'next/server'
import { connectToDatabase } from '@/lib/mongodb'

export async function GET() {
  const { db } = await connectToDatabase()
  // Your logic
  return NextResponse.json({ success: true })
}
```
