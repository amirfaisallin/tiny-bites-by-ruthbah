## 💡 Quick Tips

1. **Use relative imports** - `@/components/button` not `../../../components`
2. **Check types first** - All in `lib/mongodb.ts`
3. **Follow patterns** - Copy style from existing files
4. **Read error messages** - They're usually helpful
5. **Test locally** - Before deploying to production
6. **Use docs as reference** - Don't memorize everything
7. **Explore the code** - It's well-organized!
